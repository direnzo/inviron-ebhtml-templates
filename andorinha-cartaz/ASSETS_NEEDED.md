# INSTRUÇÕES: Adicionar Arquivos de Fonte e Backgrounds

## Fontes KOMIKA TITLE

Adicione os arquivos de fonte na pasta `css/fonts/`:

- `KOMTITP_.ttf`

## Imagens de Background

Adicione as imagens de fundo na pasta `img/backgrounds/`:

- `regular.jpg` - Fundo para condição REGULAR
- `depor.jpg` - Fundo para condição DE-POR
- `fidelidade.jpg` - Fundo para condição FIDELIDADE
- `apartirde.jpg` - Fundo para condição A-PARTIR-DE

Estas imagens serão aplicadas automaticamente de acordo com a dinâmica de preço (campo TEXTO3).

## ✅ Pronto para Teste

O template não utiliza fotos de produtos, apenas backgrounds dinâmicos. Você pode testar imediatamente após adicionar os backgrounds acima.
