# rodape-even

Template rodapé Even para EdgeContents Digital Signage.

- Baseado no rodape-teste
- Compatível com Android 7+ (ES5)
- TailwindCSS global
- Modular: clima, financeiro, notícias, mensageria, placar, horóscopo
- Configuração em js/config.js
- Mock data em js/mock-data.js

## Desenvolvimento

1. `npm run dev` para compilar CSS
2. Teste em `http://localhost:12099/FILES/1/rodape-even/index.html`
3. Ajuste módulos conforme necessidade

Consulte `/docs/README.md` para detalhes do sistema EdgeContents.
